### Added

- Seeded, cancellable noise generation and CPU image dithering for Java 8 and newer.
- Reusable GLSL and independently owned Minecraft GPU dithering passes.
- Installable Fabric library variants for Minecraft 1.21.1, 1.21.11, 26.1.x, 26.2 and 26.3, with native Vulkan support on 26.2 and 26.3.
- Plain Java utilities and source downloads. Sources include the release mapping and dependency information.
